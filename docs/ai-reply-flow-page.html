Claude Code · How it works

From your message to Claude Code's reply

A simple map of what happens after you send a chat message — with or without images.

1 The whole picture

Everything you send arrives as one message. Claude reads it, thinks, sometimes uses tools, then writes back. It can loop through tools many times before the final reply.

flowchart TD
    A([You type a message]) --> B{Any images attached?}
    B -- text only --> C[Claude reads the text]
    B -- text + image --> D[Claude reads text + looks at image]
    C --> E[Claude thinks: what is being asked?]
    D --> E
    E --> F{Need to act on your project?}
    F -- yes --> G[Use a tool: read file, run command, search, edit]
    G --> H[Tool sends back a result]
    H --> E
    F -- no --> I([Claude writes the reply])

2 The chat path

When you send only words, this is the road the message travels.

flowchart LR
    A([Your text]) --> B[Understand the request]
    B --> C[Plan the steps]
    C --> D{Enough info?}
    D -- no --> E[Ask you a question]
    D -- yes --> F[Do the work with tools]
    F --> G([Reply with the result])

3 The image path

When you attach a screenshot, photo, or diagram, Claude adds a "look at it" step before thinking.

flowchart LR
    A([You attach an image]) --> B[Claude views the picture]
    B --> C[Reads text and shapes in it]
    C --> D[Joins it with your words]
    D --> E[Thinks and acts]
    E --> F([Reply])

4 The same flow, in plain words

1

You send

Your text, and any images, go to Claude together as one message.

2

Claude looks

It reads your words. If there is an image, it looks at the image too and reads what is inside it.

3

Claude thinks

It works out what you actually want and makes a small plan.

4

Claude acts

If needed, it uses tools — open a file, run a command, search the code — and can repeat this many times.

5

Claude replies

When the work is done or a question is needed, it writes back to you.

How this helps you

You don't need to read every line Claude writes. Watch for two things: a question (Claude needs your answer) and the final reply (the result). Everything in between is Claude looking, thinking, and using tools.
